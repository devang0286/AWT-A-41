## 📖 Project Overview

The **Personalized Course Eligibility Checker** is a beginner-friendly web application that evaluates a student's eligibility for a course based on **attendance percentage** and **test marks**.

The application validates user input using **Regular Expressions (Regex)**, processes the data using JavaScript, and dynamically displays the student's eligibility status along with recommended learning topics.

------------------------------

Features

* Student Information Form
* Regular Expression (Regex) Input Validation
* Course Eligibility Calculation
* Personalized Eligibility Status
* Dynamic Learning Topic Suggestions
* DOM Manipulation
* Event Handling
* JavaScript Functions
* Conditional Statements
* Array Iteration
* Responsive User Interface
